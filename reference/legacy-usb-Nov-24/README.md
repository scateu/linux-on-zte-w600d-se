# Historical USB boot inputs, not a runnable image

These are the small original boot scripts, extlinux configuration, display
patches and DTS/DTB files from the earlier USB. Superseded Image/vmlinuz and
initrd files were deliberately removed; the cleanup report records their hashes.
Do not copy this directory wholesale to build the current Linux USB.

For current Linux use build/linux-7.3.6/ and docs/BUILD-CURRENT.md in the
consolidated root. For the optional second U-Boot/typewriter use
bootloader/usb-uboot/ and docs/USB-UBOOT-TYPEWRITER.md. Matching large files
here are relative aliases to the retained canonical files, not extra copies.
